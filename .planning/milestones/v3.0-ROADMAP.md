## Milestone Summary

**Key Decisions:**

- Web3Forms chosen over FormSubmit (FormSubmit unreachable HTTP 522 site-wide on 2026-05-19)
- og:image placed in `public/` not `src/` — Vite fingerprints src/ assets, breaking stable og:image URL
- JSON-LD Person schema inline in page head only — not in Handlebars partials (would fire on every page)
- Contact form honeypot uses `opacity:0` + `position:absolute` — `display:none` bypasses spam protection
- `cleanUrls: true` removed from vercel.json — conflicts with rewrites; rewrites alone are sufficient
- Metric chips chosen over lede-text outcomes — better visual treatment (CONT-04 wont_fix)

**Issues Resolved:**

- Nav bottom border (`.nav--scrolled` box-shadow removed)
- Hero subheadline and eyebrow label removed
- `navHome=true` added to index.html nav partial
- "Get in touch" changed from button to flat nav link
- Empty form validation gap resolved via JS validate() function

**Issues Deferred:**

- Real imagery for work__feature image placeholders (future content phase)
- Per-case-study og:image thumbnails (future asset creation)
- Google Search Console submission (post-deploy manual step)
- og:type=article on Stories post pages

**Technical Debt Incurred:**

- None material — all shortcuts documented and intentional
