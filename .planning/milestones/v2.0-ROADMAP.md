## Milestone Summary

**Key Decisions:**

- `reveal.js` uses IIFE pattern (not ES module exports) to match `typewriter.js` project convention
- State-layer `::after` documented as commented-out template in `_reveal.css` — phases copy the block
- `animation-fill-mode: both` (not `forwards`) — covers pre-delay invisibility AND post-animation hold
- Hero 1440px max-width uses `margin-inline: 0` — hero is left-aligned, not centered
- Transparent border reserve on nav links (2px transparent at rest) prevents 2px height shift on active
- Passive scroll listener with immediate `onScroll()` call handles pre-scrolled page state (bfcache, anchor)
- Two-layer nav shadow: 1px border + ambient alpha — no token needed for shadow alpha layers
- Nav font-weight changed from medium to normal per UI-SPEC typographic contract
- aria-hidden managed in all three hamburger dismiss paths (click, outside click, Escape)

**Issues Resolved:**

- Nav height bug: `var(--space-16)` (128px) → `var(--nav-height)` (56px) — affected both `.nav__inner` and `.nav__menu` top offset
- Card hover ghost state on touch devices — pointer-fine gate missing from initial implementation
- Stale light-palette box-shadow on card hover (from v1.0 light palette, incorrect on v2.0 dark palette)
- Em dashes in page titles causing typography inconsistency and potential encoding issues

**Technical Debt Deferred:**

- REQUIREMENTS.md traceability table not updated during execution (all 45 remain `[ ]`)
- ROADMAP.md progress tracking diverged from actual state
- VERIFICATION.md only created for Phase 4; Phases 2, 3, 5, 6, 7 have SUMMARY-only evidence
- Phases 5–7 SUMMARY files missing `requirements-completed:` frontmatter field
- No Nyquist VALIDATION.md files created for any phase
