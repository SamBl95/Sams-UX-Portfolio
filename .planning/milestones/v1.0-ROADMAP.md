## Key Decisions

| ID | Decision | Rationale |
|----|----------|-----------|
| D-01 | Light palette over dark | User preference; more conventional for a portfolio targeting corporate recruiters |
| D-06 | "Stories" not "Blog" | Avoids expectation of a content-heavy blog; "Stories" signals reflections and case study context |
| D-07 | `container` on all pages | User explicitly prefers full-width layouts; `container-reading` rejected |
| D-08 | Remove homepage `#contact` section | Redundant with dedicated contact page; cleaner homepage flow |
| D-09 | Nav CTA delegates to `btn--primary` | Visual consistency between nav CTA and hero CTAs; single source of truth for button style |
