## Colour Palette — Light Theme

D-13 locked: replace dark forest green with a light/neutral palette. All tokens in `_variables.css` are in scope. Direction: warm-neutral or off-white base, not pure white, not dark.

### New Token Values

| Token | New Value | Notes |
|-------|-----------|-------|
| `--color-bg` | `#f5f2ed` | Warm off-white — the dominant canvas |
| `--color-surface` | `#ede9e3` | Slightly deeper warm card/sidebar surface |
| `--color-border` | `#d6d0c8` | Subtle warm border |
| `--color-text-primary` | `#1a1614` | Near-black with warm undertone |
| `--color-text-secondary` | `#6b6560` | Muted warm-grey for secondary text |
| `--color-accent` | `#1a6b52` | Deep forest teal — dark enough on light for 4.5:1 |
| `--color-accent-accessible` | `#1a6b52` | Foreground accent; same as `--color-accent` on this palette |
| `--color-text-on-accent` | `#f5f2ed` | Warm white text ON teal backgrounds |
| `--color-accent-light` | `#e6f0ec` | Pale teal tint for chip backgrounds, tag surfaces |

Contrast guarantees:
- `--color-accent` on `--color-bg`: deep teal `#1a6b52` on `#f5f2ed` — meets WCAG AA (>4.5:1)
- `--color-text-on-accent` on `--color-accent`: warm white on deep teal — meets WCAG AA

ALWAYS use `--color-accent-accessible` for accent foreground text and focus outlines.
ALWAYS use `--color-text-on-accent` for text placed on a teal-filled background.

Shadow token update: `--shadow-accent` must be recalculated for light theme. Proposed: `0 8px 24px -4px rgb(26 107 82 / 0.18)`.

### 60/30/10 Distribution

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg` `#f5f2ed` | Page background, full-bleed sections |
| Secondary (30%) | `--color-surface` `#ede9e3` | Cards, nav bar, footer, tag chips |
| Accent (10%) | `--color-accent` `#1a6b52` | Primary CTA button fill, active nav link, focus rings, inline links on hover, hero typewriter cursor |

Accent reserved exclusively for:
1. Primary CTA button (`.btn--primary`) — fill background
2. Active nav link indicator (`.nav__link[aria-current="page"]`)
3. Focus ring outline on all interactive elements
4. Inline body-text links on `:hover`/`:focus`
5. Hero typewriter cursor

Destructive actions: none in this phase (no delete flows, no forms). Token `--color-destructive` is not introduced in phase 1.

## Typography

Source: `_variables.css`, `.claude/CLAUDE.md`. Fraunces and Urbanist are kept. This phase corrects application — sizing, weight, and hierarchy across h1–h4, body, and UI text.

### Font Weights (2 weights)

| Weight token | Value | Usage |
|-------------|-------|-------|
| `--font-weight-normal` | 400 | Body copy, meta/date/caption, post summary, secondary labels |
| `--font-weight-semibold` | 600 | h1, h2, h3, h4, nav links, CTA button labels, UI labels, Stories post titles |

`--font-weight-medium` 500 and `--font-weight-bold` 700 are not used in this phase.

### Type Scale — 4 Semantic Size Roles

All text in this phase maps to exactly one of these four roles:

| Role | Font | Size Token | Weight | Line Height | Maps To |
|------|------|-----------|--------|-------------|---------|
| **Display** (h1 only) | Fraunces | `--text-56` → `--text-80` (responsive) | `--font-weight-semibold` 600 | `--leading-tight` 1.25 | Hero h1, Stories post h1 |
| **Heading** (h2–h3) | Fraunces | `--text-28` → `--text-40` (responsive) | `--font-weight-semibold` 600 | `--leading-tight` 1.25 | Section h2, card h3, post h2s, Contact page heading |
| **Body** | Urbanist | `--text-base` 16px | `--font-weight-normal` 400 | `--leading-body` 1.7 | Body paragraphs, post body, Contact intro |
| **Meta** | Urbanist | `--text-sm` 14px | `--font-weight-normal` 400 or `--font-weight-semibold` 600 | `--leading-normal` 1.5 | Nav links, CTA labels, post titles in Stories index, post dates, captions, "What I'm interested in" list |

Notes:
- `--text-xs` 12px is retired from this phase. Dates and captions use Meta role at `--text-sm` 14px.
- `--text-lg` 1.125rem and `--text-xl` 1.25rem are not active size entries in this phase.
- Stories index post title: Meta role, `--font-weight-semibold` 600.
- In-post h2 headings: Heading role, `--text-28` Fraunces `--font-weight-semibold`.

### Responsive Heading Sizes (mobile-first)

| Role | ≤600px | 600px | 905px | 1240px |
|------|--------|-------|-------|--------|
| Display / h1 | `--text-40` | `--text-56` | `--text-64` | `--text-80` |
| Heading / h2 | `--text-28` | `--text-32` | `--text-40` | `--text-40` |
| Heading / h3 | `--text-22` | `--text-22` | `--text-28` | `--text-28` |

Optical sizing: apply `font-optical-sizing: auto` to all Fraunces headings. Already in scope per `.claude/CLAUDE.md`.

## Layout Contract

Source: CONTEXT.md D-15 + layout direction confirmed by user in this session.

### Focal Point Declaration

Primary visual anchor: hero h1 with typewriter animation. All other elements on the first viewport are secondary to this anchor. No competing focal points (no large imagery, no hero subheading at display scale, no floating UI elements) should appear alongside the h1 on initial load.

### Layout Mode: Full-Width Editorial

Hero text spans full width, constrained only by the existing `container-wide` class. Cards grid fills the window. No secondary max-width cap imposed on the hero text column.

**Reading sections** (contact page, Stories post pages): use `container-reading` at **720px max-width**. These are inherently long-form and require comfortable line length.

### Container Widths

| Container | Max-width | Usage |
|-----------|-----------|-------|
| `container-wide` | 1440px | Homepage, about page, case study pages — editorial content |
| `container-reading` | 720px | Contact page content, Stories post body copy |

### Breakpoints

Mobile-first. Breakpoints defined in `_breakpoints.css`:

| Breakpoint | Width | Trigger |
|------------|-------|---------|
| sm | 600px | Single-column → two-column card grid |
| md | 905px | Nav: collapse hamburger → full links |
| lg | 1240px | Hero text scales up, grid columns expand |
| xl | 1440px | Container caps out — content centres within viewport |

### Section Vertical Rhythm

- Mobile: `--space-6` (48px) top/bottom per section
- Desktop (≥905px): `--space-10` (80px) top/bottom per section
- Hero: `--space-12` (96px) top, `--space-10` (80px) bottom on desktop

### Card Grid

- Mobile: 1 column
- 600px: 2 columns, `gap: --space-4`
- 905px: 2 columns (maintain — cards are large editorial items)
- 1240px: 3 columns if 3+ cards; 2 columns otherwise

## Navigation Contract

Source: CONTEXT.md D-01 through D-06.

### Nav Structure

```
[Logo/Name] .............. [Work] [About] [Stories] [Get in touch →]
```

- "Get in touch" is a CTA-styled link, not a plain nav link — uses `.nav__link--cta` with accent treatment
- Active state: `aria-current="page"` on the current page's link + `.nav__link--active` visual class (underline or accent colour, Claude's discretion per D-03)
- Mobile: hamburger button toggles `.nav--open` on `.nav`, `aria-expanded` on button

### Nav Visual Spec

| State | Visual |
|-------|--------|
| Default link | `--color-text-primary`, `--font-weight-semibold` (Meta role) |
| Hover link | `--color-accent`, transition `--transition-fast` |
| Active link (`aria-current`) | `--color-accent`, `--font-weight-semibold` |
| CTA link ("Get in touch") | Border or background using `--color-accent`, `--color-text-on-accent` if filled |
| Nav bar background | `--color-surface` |
| Nav bar border-bottom | 1px `--color-border` |

## Interaction Contract

| Interaction | Behaviour | Timing |
|-------------|-----------|--------|
| Nav link hover | Colour transitions to `--color-accent` | `--transition-fast` 150ms `--ease-out` |
| CTA button hover | Slight scale `1.02` + shadow lift | `--transition-fast` 150ms `--ease-out` |
| Nav hamburger open/close | `.nav--open` class toggle + `aria-expanded` update | instant (CSS transition on nav panel) |
| Nav mobile menu open | Panel slides or fades in | `--transition-base` 200ms `--ease-out` |
| Focus rings | `outline: 2px solid var(--color-accent-accessible)`, `outline-offset: 3px` | instant |
| Stories list row hover | Background tint `--color-accent-light` | `--transition-fast` 150ms |

`prefers-reduced-motion`: all transitions collapse to instant when `@media (prefers-reduced-motion: reduce)` matches.
