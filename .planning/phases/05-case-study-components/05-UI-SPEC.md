## Spacing Scale

This phase uses the established 8pt scale tokens. All spacing **must** reference these tokens.

| Token | Value | Phase 5 Usage |
|-------|-------|---------------|
| --space-1 | 8px | Gap inside label chips; icon gaps; step number internal gap |
| --space-2 | 16px | Figcaption top gap; chip padding inline; between-label spacing |
| --space-3 | 24px | Callout body text gap; pull-quote cite gap; step body gap |
| --space-4 | 32px | Before/after column gap (mobile stacked block spacing) |
| --space-5 | 40px | Callout padding block; pull-quote padding block |
| --space-6 | 48px | Callout padding inline; process-steps item padding |
| --space-8 | 64px | Two-column gap (desktop); metrics-row item padding; image-block margin-block |
| --space-10 | 80px | Image-block margin-block at 905px+; process-steps connector vertical spacing |
| --space-12 | 96px | Section-level margin-block for embedded image-block full variant |

Exceptions:
- Process step counter circle: 40px diameter (5 × 8 = 40px — aligns to scale, use `--space-5` as a width/height value)
- Before/after label chips: `padding: 4px var(--space-2)` — 4px is a half-step; permissible for compact chip typography

## Component Contracts

### CS-01 — `_image-block.css`

**HTML structure:** `<figure class="image-block image-block--{variant}">` wrapping `<img>` + `<figcaption class="image-block__caption">`.

**Variants:**

| Modifier | Behavior |
|----------|----------|
| `.image-block--full` | Breaks out of prose flow; full-bleed `width: 100%`; max-width unconstrained within container |
| `.image-block--contained` | Default; stays within prose column; `max-width: 100%` on image |
| `.image-block--aside` | Floated right at 905px+; `width: 40%`; `margin-left: var(--space-8)`; stacks on mobile |

**Sizing:**
- Image: `display: block; width: 100%; height: auto; border-radius: var(--radius-lg)`
- Full variant image: `border-radius: 0` (edge-to-edge if full-bleed)
- Margin block (contained + aside): `margin-block: var(--space-8)` mobile, `var(--space-10)` at 905px+

**Caption:**
- `margin-top: var(--space-2)`, `font-size: var(--text-sm)`, `color: var(--color-text-secondary)`, `line-height: var(--leading-relaxed)`
- `font-style: italic`; matches existing figcaption convention

**Aside clearfix:** `.image-block--aside::after { content: ''; display: table; clear: both; }` — avoids float bleed in prose.

**Accessibility:** `<figure>` is implicit landmark; `<figcaption>` linked by DOM proximity; no `role` override needed.

### CS-02 — `_callout.css`

**HTML structure:** `<aside class="callout callout--{variant}" role="note">` containing `<p class="callout__eyebrow">` (optional) + `<p class="callout__body">`.

Quote variant uses `<blockquote class="callout callout--quote">` + `<cite class="callout__cite">`.

**Shared base:**
- `padding: var(--space-5) var(--space-6)`
- `margin-block: var(--space-8)`
- `border-radius: 0 var(--radius-md) var(--radius-md) 0`
- `border-left: 3px solid {variant color}`

**Variant styles:**

| Variant | Background | Border-left | Body style |
|---------|------------|-------------|------------|
| `.callout--insight` (default) | `--color-accent-light` | `--color-accent` | normal |
| `.callout--warning` | `--color-surface` | `--color-border` | normal |
| `.callout--quote` | transparent | `--color-border` | `font-style: italic` |

**Eyebrow (optional):**
- `font-size: var(--text-xs)`, `font-weight: var(--font-weight-semibold)`, `letter-spacing: 0.06em`, `text-transform: uppercase`, `color: var(--color-accent-accessible)`, `margin-bottom: var(--space-2)`
- Only used in insight variant; absent from warning/quote

**Body:** `font-size: var(--text-base)`, `line-height: var(--leading-relaxed)`, `color: var(--color-text-primary)`, `margin: 0`

**Cite (quote variant only):** `display: block`, `font-size: var(--text-sm)`, `color: var(--color-text-secondary)`, `font-style: normal`, `margin-top: var(--space-3)`

**Accessibility:** `role="note"` on `<aside>` for insight/warning; `<blockquote>` is self-describing for quote variant.

### CS-03 — `_pull-quote.css`

**HTML structure:** `<blockquote class="pull-quote">` containing `<p class="pull-quote__text">` + optional `<cite class="pull-quote__cite">`.

**Visual contract:**
- Left accent bar: `::before` pseudo — `width: 3px`, `height: 100%`, `background-color: var(--color-accent)`, `position: absolute; left: 0; top: 0`
- Outer: `position: relative`, `padding-left: var(--space-6)`, `margin-block: var(--space-10)`, `border: none` (override default blockquote border)

**Typography:**
- `.pull-quote__text`: `font-family: var(--font-heading)`, `font-size: var(--text-3xl)` (mobile), `var(--text-4xl)` at 905px+, `font-weight: var(--font-weight-semibold)`, `line-height: var(--leading-tight)`, `letter-spacing: -0.02em`, `color: var(--color-text-primary)`
- `.pull-quote__cite`: `display: block`, `margin-top: var(--space-3)`, `font-size: var(--text-sm)`, `font-weight: var(--font-weight-medium)`, `font-style: normal`, `color: var(--color-text-secondary)`

**No interactive states.** Static display component.

### CS-04 — `_process-steps.css`

**HTML structure:** `<ol class="process-steps">` containing `<li class="process-steps__item">` each with `.process-steps__heading` + `.process-steps__body`.

**Counter system:**
```css
.process-steps { counter-reset: step; }
.process-steps__item { counter-increment: step; }
.process-steps__item::before {
  content: counter(step);
  /* circle dimensions, font, color below */
}
```

**Step counter circle:**
- `display: flex; align-items: center; justify-content: center`
- `width: var(--space-5); height: var(--space-5)` (40px × 40px)
- `border-radius: var(--radius-full)`
- `border: 2px solid var(--color-accent)`
- `color: var(--color-accent-accessible)`
- `font-family: var(--font-heading)`, `font-size: var(--text-base)`, `font-weight: var(--font-weight-semibold)`, `letter-spacing: -0.01em`
- `flex-shrink: 0`

**Step item layout:**
- Mobile: `display: flex; flex-direction: column; gap: var(--space-3)`
- Desktop (905px+): `display: grid; grid-template-columns: var(--space-5) 1fr; gap: var(--space-6); align-items: start`

**Connector line (905px+ only):**
- `position: relative` on `.process-steps__item`
- `::after` pseudo — `width: 2px`, centered under the counter circle, `top: var(--space-5)`, `height: calc(100% + var(--space-6))` (bridges gap to next item), `background-color: var(--color-accent)`, `opacity: 0.3`
- Last item: `.process-steps__item:last-child::after { display: none }`

**Spacing:**
- `.process-steps`: `display: flex; flex-direction: column; gap: var(--space-6)` mobile, `var(--space-8)` at 905px+
- `.process-steps__heading`: `var(--text-base)`, `--font-weight-semibold`, `--color-text-primary`, `margin-bottom: var(--space-1)`
- `.process-steps__body`: `var(--text-base)`, `--font-weight-normal`, `--color-text-secondary`, `--leading-relaxed`

### CS-05 — `_before-after.css`

**HTML structure:**
```html
<div class="before-after">
  <div class="before-after__col before-after__col--before">
    <span class="before-after__label">Before</span>
    <!-- content -->
  </div>
  <div class="before-after__col before-after__col--after">
    <span class="before-after__label">After</span>
    <!-- content -->
  </div>
</div>
```

**Layout:**
- Mobile: `display: flex; flex-direction: column; gap: var(--space-4)`
- 905px+: `display: grid; grid-template-columns: 1fr 1fr; gap: var(--space-8); align-items: start`

**Column:**
- `background-color: var(--color-surface)`
- `border: 1px solid var(--color-border)`
- `border-radius: var(--radius-xl)`
- `padding: var(--space-6)`
- `display: flex; flex-direction: column; gap: var(--space-3)`

**Label chip:**
- `display: inline-flex; align-items: center`
- `padding: 4px var(--space-2)` (4px top/bottom — documented exception)
- `border-radius: var(--radius-full)`
- `font-size: var(--text-xs)`, `font-weight: var(--font-weight-semibold)`, `letter-spacing: 0.06em`, `text-transform: uppercase`
- Before label: `border: 1px solid var(--color-border)`, `color: var(--color-text-secondary)`, `background-color: transparent`
- After label: `border: 1px solid var(--color-accent)`, `color: var(--color-accent-accessible)`, `background-color: var(--color-accent-light)`

**No JS dependency** — pure CSS layout. No interactive states beyond link focus if column content includes links.

### CS-06 — `_metrics-row.css`

**HTML structure:** `<ul class="metrics-row">` containing `<li class="metrics-row__item">` each with `.metrics-row__value` + `.metrics-row__label`.

**Layout:**
- Mobile: `display: grid; grid-template-columns: repeat(2, 1fr); gap: var(--space-8) var(--space-6)` (2-col, maintains visual rhythm)
- 905px+: `display: flex; flex-direction: row` — 2–3 items fill naturally; `gap: 0`

**Item (905px+ horizontal dividers):**
- `padding-inline: var(--space-8)`
- `border-left: 1px solid var(--color-border)`
- First child: `padding-left: 0; border-left: none`
- Last child: `padding-right: 0`

**Value:**
- `font-family: var(--font-heading)`, `font-size: var(--text-4xl)` mobile, `var(--text-5xl)` at 905px+
- `font-weight: var(--font-weight-bold)`, `line-height: 1`, `letter-spacing: -0.02em`
- `color: var(--color-accent-accessible)`
- Decorative accent underline via `::after`: `width: var(--space-8)` (64px), `height: 2px`, `background-color: var(--color-accent)`, `border-radius: var(--radius-full)`, `margin-top: var(--space-3)` — exact pattern from `_stat-block.css`

**Label:**
- `font-size: var(--text-sm)`, `font-weight: var(--font-weight-normal)`, `line-height: var(--leading-normal)`, `color: var(--color-text-secondary)`, `max-width: 18ch`

Note: This component mirrors `_stat-block.css` closely. The distinction is context: `metrics-row` is embedded inline in case study body prose, while `stat-row` is a full-width homepage section strip. Keep as a separate file to avoid coupling — layout differences (no full-bleed surface background) justify separation.

### CS-07 — `_two-column.css`

**HTML structure:** `<div class="two-col">` containing two direct children (any semantic element).

**Layout:**
- Mobile: `display: flex; flex-direction: column; gap: var(--space-8)`
- 905px+: `display: grid; grid-template-columns: 1fr 1fr; gap: var(--space-8); align-items: start`

**Modifiers:**
- `.two-col--asymmetric`: `grid-template-columns: 2fr 1fr` at 905px+ — allows wide content + narrow sidebar arrangement
- `.two-col--valign-center`: `align-items: center` — for image + text pairs where vertical centering is needed

This is a layout utility only — no background, no border, no typography declarations. Content styles come from child components placed inside it.

## Copywriting Contract

These components contain no fixed UI copy — they are structural shells. Content (captions, callout text, metrics, process step descriptions) is authored by the case study writer. The contract below documents structural copy patterns that constrain authoring.

| Element | Pattern | Constraint |
|---------|---------|------------|
| Image caption | Descriptive phrase, present tense | ≤20 words; no ending period |
| Callout eyebrow | Noun phrase, uppercase | ≤3 words; only for insight variant |
| Callout body | Insight or verbatim quote | 1–3 sentences max |
| Pull-quote text | Single insight sentence | ≤25 words; no quotation marks in markup |
| Pull-quote cite | "Name, Role" or "Source, Year" | Attribution only; no punctuation at end |
| Process step heading | Verb phrase, title case | ≤6 words |
| Process step body | One-paragraph explanation | 2–4 sentences |
| Before label chip | "Before" | Fixed — do not vary |
| After label chip | "After" | Fixed — do not vary |
| Metrics value | Number + optional unit (%, x, s) | No surrounding text; unit inline |
| Metrics label | Outcome phrase | ≤8 words, sentence case |

Empty states: Not applicable — these components only render when content is present.
Error states: Not applicable — static HTML.
Destructive actions: None in this phase.
