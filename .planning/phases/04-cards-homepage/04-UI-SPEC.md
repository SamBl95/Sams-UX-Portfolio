## Interaction Contract

### COMP-02 — State-Layer Hover

**Pattern:** `::after` pseudo-element overlay. Copy from the documented block in `_reveal.css` (lines 71–98).

```
.card {
  position: relative;   /* required for ::after positioning */
}

.card::after {
  content:          '';
  position:         absolute;
  inset:            0;
  border-radius:    inherit;
  background-color: var(--color-text-primary);
  opacity:          0;
  transition:       opacity 150ms var(--ease-out);
  pointer-events:   none;
}

@media (hover: hover) and (pointer: fine) {
  .card:hover::after { opacity: 0.08; }
}

.card:active::after { opacity: 0.12; }
```

Remove the existing `background-color: var(--color-surface)` swap on `:hover`.
Retain `translateY(-6px)` lift and `border-color` accent transition — these are additive, not replaced.

### COMP-03 — Link Arrow on Card Hover

The arrow translate currently fires only on `.btn--ghost:hover`. Change the selector to fire on `.card:hover` instead:

```
@media (hover: hover) and (pointer: fine) {
  .card:hover .card__link-arrow {
    transform: translateX(var(--space-1));   /* 8px */
  }
}
```

Transition already set on `.card__link-arrow`: `150ms var(--ease-out)`. No change needed there.

### COMP-04 — Card Active Press

```
.card:active {
  transform: scale(0.97);
}
```

Consistent with button `scale(0.97)` press pattern (BTN-04). Uses existing `transform` transition on `.card`: `200ms var(--ease-in-out)`.

### COMP-05 — Hover Media Query Gate

Current card hover block uses `@media (hover: hover)` only. Add `pointer: fine`:

```
/* Before: */
@media (hover: hover) { ... }

/* After: */
@media (hover: hover) and (pointer: fine) { ... }
```

### ANIM-03 — Scroll-Stagger (Three Cards)

Apply `.js-reveal` to each `.card` element. Use `data-reveal-delay` attributes for 0 / 100 / 200ms stagger:

```html
<div class="card js-reveal" data-reveal-delay="0">...</div>
<div class="card js-reveal" data-reveal-delay="100">...</div>
<div class="card js-reveal" data-reveal-delay="200">...</div>
```

The `reveal-enter` keyframe (`translateY(20px) → translateY(0)`, opacity 0→1, 500ms `--ease-out-quint`) is already declared in `_reveal.css`. No new keyframes needed.

Note: `data-reveal-delay="0"` is implicit (no delay attribute needed for first card, but explicit for clarity). Delay tokens already declared in `_reveal.css` for 100ms and 200ms.

`animation-fill-mode: both` — already set in `_reveal.css` (`both` keyword covers pre-animation invisible state AND post-animation hold). Source: STATE.md Phase 3 decision.

### Card Hover Lift (retain, adjust)

`transform: translateY(-6px)` — retain. Transition: `200ms var(--ease-in-out)`.

Note: `transform` carries both the lift (`translateY`) and press (`scale`) values. When card is both hovered and active, `scale(0.97)` should override lift. CSS specificity handles this naturally since `:active` has higher specificity than `:hover` when both are present. No `transform` value conflict if declared in the correct order (hover first, active second).

## Layout Contract

### LAY-02 — Three-Column Grid at 1240px+

Add a new breakpoint to `.case-studies__grid`:

```css
@media (min-width: 1240px) {
  .case-studies__grid {
    grid-template-columns: repeat(3, 1fr);
    gap: var(--space-8);   /* 64px */
  }
}
```

This ensures all three cards display in a single row with equal width. No orphaned card at any supported viewport.

Breakpoint ladder (complete):
| Breakpoint | Columns | Gap |
|------------|---------|-----|
| default (mobile) | 1 | --space-2 (16px) |
| 600px+ | 1 | --space-3 (24px) |
| 905px+ | 2 | --space-4 (32px) |
| 1240px+ | 3 | --space-8 (64px) |

Source: REQUIREMENTS.md LAY-02; `_case-studies.css` existing breakpoints.

## Reduced Motion Contract

Every interaction in this phase must have a `prefers-reduced-motion: reduce` counterpart.

| Interaction | Reduced-motion behaviour |
|-------------|--------------------------|
| Card scroll-reveal stagger (ANIM-03) | `.js-reveal` / `.js-reveal--visible` reduced-motion block already in `_reveal.css` — opacity restored, animation: none. No additional work needed. |
| Card hover lift (translateY(-6px)) | Wrap in `@media (hover: hover) and (pointer: fine)` only. Add: `@media (prefers-reduced-motion: reduce) { .card { transition: none; } }` or scope lift transform inside a `not (prefers-reduced-motion: reduce)` block. |
| State-layer transition | `transition: opacity 150ms` on `::after`. Under reduced motion: `transition: none` on `.card::after`. |
| Card active scale press | `scale(0.97)` is a micro-interaction with no `animation-duration`. The global reset zeros `transition-duration` — the press will still work but snap rather than animate. This is acceptable behaviour. |

## Copywriting Contract

This phase has no new page content, empty states, or error states. The card component contains fixed-structure copy slots populated by HTML content. The contract below documents the structural copy patterns.

| Element | Pattern | Example |
|---------|---------|---------|
| Metric value | Number + unit, Fraunces, teal | "42%" |
| Metric label | Outcome phrase, ≤6 words, sentence case | "reduction in support tickets" |
| Card title | Project or initiative name, title case | "i-exchange Redesign" |
| Card subtitle | One-sentence outcome, ≤20 words | "Redesigned the trading dashboard to reduce task time by 42%." |
| Sector tags | Sector noun, title case, comma-separated chips | "Fintech", "UX Research" |
| Read time | "{N} min read" | "5 min read" |
| Link CTA | "Read case study" + arrow icon | "Read case study →" |

Empty state: Not applicable — cards always have content in this phase.
Error state: Not applicable — static HTML, no async data loading.
Destructive actions: None in this phase.

Source: existing card markup patterns; REQUIREMENTS.md COMP-01 through COMP-05.
