  <name>Task 1: Create form.js — AJAX submission with success/error states</name>
  <files>src/form.js</files>
  <read_first>
    src/pages/contact.html — understand existing DOM structure before adding JS
  </read_first>
  <behavior>
    - JS attaches to a form with id="contact-form" via addEventListener('submit')
    - Calls event.preventDefault() to block native form submission
    - Reads name (#contact-name), email (#contact-email), message (#contact-message) field values
    - Checks honeypot field value (_honey): if non-empty, silently returns without submitting
    - POSTs JSON body { name, email, message } to https://formsubmit.co/ajax/sam.blake@outlook.com with Accept: application/json and Content-Type: application/json
    - On response.ok AND parsed json.success === "true": hides the form element, shows .form__success element
    - On any failure (network error, non-ok response, success !== "true"): shows .form__error element; does NOT hide the form so the user can retry
    - Adds .form--loading class to the form during fetch (removes after); this class can be used by CSS to disable the submit button
    - Error catch block covers fetch rejections (network offline)
  </behavior>
  <action>
    Create src/form.js as an ES module (no IIFE wrapper needed — loaded via type="module").

    The file exports nothing. It runs on DOMContentLoaded.

    DOM query targets:
    - form: document.getElementById('contact-form')
    - success panel: document.querySelector('.form__success')
    - error panel: document.querySelector('.form__error')
    - honeypot: form.querySelector('[name="_honey"]')

    Submit handler logic:
    1. Add class 'form--loading' to form, disable the submit button.
    2. Collect values: name = form.querySelector('#contact-name').value.trim(), email = form.querySelector('#contact-email').value.trim(), message = form.querySelector('#contact-message').value.trim().
    3. If honeypot value is non-empty, remove 'form--loading', re-enable submit, return silently.
    4. fetch('https://formsubmit.co/ajax/sam.blake@outlook.com', { method: 'POST', headers: { 'Accept': 'application/json', 'Content-Type': 'application/json' }, body: JSON.stringify({ name, email, message }) }).
    5. On success (response.ok AND json.success === 'true'): form.hidden = true; document.querySelector('.form__success').hidden = false.
    6. On failure: remove 'form--loading', re-enable submit, document.querySelector('.form__error').hidden = false.
    7. Wrap in try/catch — catch block runs the same failure path as step 6.
  </action>
  <verify>
    Open contact page in browser. In DevTools Network tab, submit the form — verify a POST to formsubmit.co/ajax appears. No page navigation occurs.
    In JS console: temporarily set response to error (mock with DevTools offline mode) — verify .form__error becomes visible and form remains present.
  </verify>
