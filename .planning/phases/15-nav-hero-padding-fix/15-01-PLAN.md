<objective>
Fix the vertical alignment of the H1 on the About and CV pages so it sits at the same distance below the nav as on case study pages.

Purpose: The .about-hero section has no back-link element before the H1. Case study pages have a .cs-hero__back element that contributes approximately 84px of vertical space (margin-bottom: var(--space-8) = 64px plus ~20px line height) before the H1. Without a compensating padding-top override on .about-hero, the H1 appears 84px too high relative to case study pages.

Output: A padding-top override added to .about-hero in _about.css, responsive at both mobile (< 905px) and desktop (>= 905px), using only --space-* tokens.
</objective>

Token candidates from UI-SPEC:

Next larger token if first trial is still too low:
