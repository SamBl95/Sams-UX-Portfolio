  <action>
    Edit src/styles/3-components/_card.css. Insert a new block directly after the `.card { ... }` surface block (after the closing brace of the `.card:active { transform: scale(0.97); }` rule and the `@media (prefers-reduced-motion: reduce)` block) and before the `/* METRIC CHIP */` comment section.

    Add this block:

    /* -------------------------------------------------------------------------
       CARD IMAGE — thumbnail at top of card, above the metric chip
       ------------------------------------------------------------------------- */

    .card__image {
      aspect-ratio:     16 / 9;
      overflow:         hidden;
      flex-shrink:      0;
      background-color: var(--color-surface);
    }

    .card__image img {
      width:      100%;
      height:     100%;
      object-fit: cover;
      display:    block;
    }

    Notes on this CSS:
    - `aspect-ratio: 16 / 9` enforces the image ratio without a padding-top hack.
    - `overflow: hidden` clips the img to the aspect-ratio box. The parent `.card` already has `overflow: hidden` and `border-radius: var(--radius-xl)` — the top corners of the image will be clipped by the card's own overflow hidden, so no additional border-radius is needed on `.card__image`.
    - `flex-shrink: 0` prevents the image from collapsing in the card's flex column layout.
    - `width: 100%; height: 100%` on the img together with `object-fit: cover` fills the ratio box without distortion.
    - `display: block` removes the 4px inline gap below the img element.
    - Do NOT remove or alter any existing rule. Do NOT add hex values.
    - The `.card__metric-chip` rule that follows already has `border-top: 3px solid var(--color-accent)` — the image sits above this accent border, which remains visually intact.
  </action>
