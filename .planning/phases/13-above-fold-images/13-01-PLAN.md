    i-Exchange feature row — replace the empty div with:

        &lt;img
          src="/assets/images/i-exchange-preview.png"

          loading="lazy"
          decoding="async"
        /&gt;
      &lt;/div&gt;

    Cassi feature row — replace the empty div with:
      &lt;div class="work__feature-image"&gt;
        &lt;img
          src="/assets/images/cassi-preview.png"
          alt=""
          width="800"
          height="450"
          loading="lazy"
          decoding="async"
        /&gt;
      &lt;/div&gt;

    Community feature row — replace the empty div with:
      &lt;div class="work__feature-image"&gt;
        &lt;img
          src="/assets/images/community-preview.png"
          alt=""
          width="800"
          height="450"
          loading="lazy"
          decoding="async"
        /&gt;
      &lt;/div&gt;

    Rules:
    - `alt=""` (empty string, not omitted) — these are contextual images where the surrounding h2 and description already describe the content; empty alt is correct accessibility practice for decorative/contextual images inside labelled links.
    - `loading="lazy"` — the feature rows are the main content of /work but will be partially off-screen on mobile; lazy loading is appropriate.
    - `decoding="async"` — parallel decoding, no render blocking.
    - `width="800" height="450"` — matches 16:9 ratio, prevents CLS by reserving space before image loads.
    - Do NOT add inline styles. Do NOT add a class other than those already in the file.
  </action>
